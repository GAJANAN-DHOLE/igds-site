### The underlying difference

A three-phase supply produces a rotating magnetic field, so a three-phase motor starts on its own. A single-phase supply alternates in one direction, which cannot start the motor, so single-phase motors use a start winding and a capacitor to create the push.

### What changes in the starter

**Single-phase starters** manage the start and run capacitors, engage the start circuit and release it once the motor is up to speed. They watch current, because a failed capacitor or a stalled pump shows up there first.

**Three-phase starters** switch three conductors and watch all of them. Phase failure, phase sequence and voltage unbalance matter here, because a motor running on two phases can overheat quickly.

### Choosing between them

You rarely choose freely. Small installations on a single-phase connection use single-phase motors, typically up to a few HP. Larger pumps go on three-phase where it is available. If you have the choice, three-phase motors are generally more efficient and simpler.

### What both need

Overload protection, dry-run detection, and under and over voltage cut-outs. A pump that runs dry fails quickly whatever its supply.
